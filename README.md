# Books Parser

Парсер каталога интернет-магазина: собирает все товары с сайта и сохраняет их в Excel.

В качестве примера используется [books.toscrape.com](https://books.toscrape.com) — учебный книжный магазин, созданный для тренировки парсинга. Парсер проходит все 50 страниц каталога и собирает 1000 книг.

## Что собирается

| Поле | Пример |
|---|---|
| Название | A Light in the Attic |
| Цена (£) | 51.77 |
| Рейтинг (1–5) | 3 |
| В наличии | да |
| Ссылка | https://books.toscrape.com/catalogue/a-light-in-the-attic_1000/index.html |

Цена и рейтинг сохраняются числами, поэтому в Excel их можно сортировать, фильтровать и суммировать.

## Возможности

- обход всех страниц каталога через кнопку «next»
- пауза между запросами, чтобы не нагружать сайт
- таймаут и проверка ответа сервера: при ошибке парсер останавливается с понятным сообщением
- вывод прогресса в консоль
- результат в файле `books.xlsx`

## Стек

Python 3, requests, BeautifulSoup4, openpyxl

## Установка и запуск

```bash
git clone https://github.com/kirimarakaev-art/books-parser.git
cd books-parser
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

Пример вывода:

```
Страница 1: найдено 20 книг
Страница 2: найдено 20 книг
...
Страница 50: найдено 20 книг
Готово: 1000 книг сохранено в books.xlsx
```

## Структура проекта

```
books-parser/
├── main.py           # точка входа: обход страниц и сохранение результата
├── fetcher.py        # загрузка страниц
├── parser.py         # разбор HTML и извлечение данных
├── exporter.py       # сохранение в Excel
├── models.py         # модель данных Book
└── requirements.txt  # зависимости
```

Загрузка, разбор и сохранение разделены по модулям: при изменении вёрстки сайта правится только `parser.py`, а для другого формата выгрузки (CSV, Google Sheets, база данных) — только `exporter.py`.

## Настройки

В начале `main.py`:

- `START_URL` — с какой страницы начинать
- `OUTPUT_FILE` — имя файла с результатом
- `DELAY` — пауза между запросами в секундах
